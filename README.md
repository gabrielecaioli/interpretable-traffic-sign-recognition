# Interpretable Traffic Sign Recognition — Intelligent Systems Project

This repository contains the code and documentation for the **Intelligent Systems Project (A.Y. 2025/2026)**.

The project implements a complete pipeline for **Traffic Sign Detection and Classification**, combining the state-of-the-art object detector **YOLOv8** with **ProtoTree** (a Prototypical Part-based Decision Tree) for **Explainable AI (XAI)**.

---

## Key Features

1. **YOLOv8 Object Detection**: Fast and accurate detection of traffic signs (200 classes)
2. **Explainable Classification (ProtoTree)**: Local and global explainability of traffic sign classifications using prototype-based decision trees ("this looks like that").

## Prerequisites & Installation

### 1. Requirements
* **Python 3.8+**
* **CUDA-compatible GPU** (highly recommended for YOLO and ProtoTree training)
* **Graphviz** (required for generating ProtoTree decision tree visualization PDFs and PNGs)
  * macOS: `brew install graphviz`
  * Ubuntu: `sudo apt-get install graphviz`

To install the necessary python packages:

## How to Run the Pipeline

The entire project is structured inside a single, unified Jupyter Notebook: `src/traffic_signs_IS_project.ipynb`.

### Step 1: Clone the Repository
```bash
git clone https://github.com/gabrielecaioli/interpretable-traffic-sign-recognition.git
cd interpretable-traffic-sign-recognition
```

### Step 2: Prepare the Dataset
The project is built on the **DFG Traffic Sign Dataset**. You need to download it manually (available on the [official DFG resource page](https://www.vicos.si/resources/dfg/)):
1. **Download the images**: [JPEGImages.tar.bz2](https://go.vicos.si/dfgimages)
2. **Download the annotations**: [DFG-tsd-aug-annot-json-with-difficult-samples.zip](https://go.vicos.si/dfgaugannotdiff)

Once downloaded, set up your local `dataset/` directory (which is not present initially) as follows:
* Create `dataset/images/` and extract the contents of `JPEGImages.tar.bz2` inside it.
* Create `dataset/labels/`, extract the DFG zip annotations, and place the JSON file inside it renaming it to `labels.json` (so the path is `dataset/labels/labels.json`).

*(Note: All other directories like `checkpoints/`, `crops_split/`, `results/`, and `splits/` will be automatically generated by the notebook cells during execution).*

**Optional — test video**: to run the video pipeline (Section 14), place a dash-cam video named `dash-cam.mov` in the repository root. The annotated output is saved as `output_dash-cam.mov` in the same folder (videos are ignored by git).

### Step 3: Run the Jupyter Notebook
Open the notebook:
```bash
jupyter notebook src/traffic_signs_IS_project.ipynb
```

Execute the cells sequentially. The notebook will automatically:
1. **Convert** COCO annotations to YOLO format `.txt` files (Section 3).
2. **Generate K-Fold splits** (Section 5) inside the `splits/` directory.
3. **Compare YOLO scales** (nano to xlarge) on Fold 0 (Section 6).
4. **Optimize hyperparameters** (Section 7) and train the best configuration on all 5 folds (Section 8).
5. **Extract sign crops** (Section 10) to train **ProtoTree** (Section 11).
6. **Prune and project** the decision tree to inspect and visualize the learned prototypes (Section 12).
7. **Run the End-to-End Pipeline** on static test images (Section 13) and test videos (Section 14).
